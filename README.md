# StudyCircle

NSBM StudyCircle is a student community platform for sharing lecture notes,
asking academic questions, and forming study groups.

## Technologies
- HTML, CSS, JavaScript
- PHP
- MySQL

## Features
- Admin and student login
- Upload and download study materials
- Discussion forum
- Study groups and sessions

## How to run locally
1. Install XAMPP and start Apache and MySQL.
2. Copy this folder into `C:\xampp\htdocs\`.
3. Import `sql/studycircle.sql` in phpMyAdmin.
4. Open `http://localhost/studycircle/`.
